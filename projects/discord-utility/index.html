Что нового

  • Ядро обновляется напрямую из стабильных релизов Flowseal — без ожидания новой версии ByPass.
  • После смены ядра подключение восстанавливается автоматически. Если запуск не удался, возвращается прежнее ядро.
  • Пользовательские списки сайтов и игровые настройки сохраняются. В комплекте — ядро 1.10.4.

Технологии / направления

Windows / Настольное приложение

Управление в одном окне

Выбор стратегии, автоподбор, диагностика, правила сайтов и обновления собраны в Windows-интерфейсе. Закрытие окна сворачивает приложение в трей; скачивание обновления запускается отдельным действием.

Это самостоятельная оболочка для Flowseal zapret. Для запуска нужны Windows 10/11 x64 и .NET Framework 4.8; работа драйвера требует прав администратора.
