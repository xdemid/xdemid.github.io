Инструмент Unity В разработке

Playable State Machine

Визуальные состояния, переходы и события для игровых сценариев в Unity.

Роль

Личный инструмент; подробное распределение авторства ещё не описано.

Технологии / направления

Unity / Инструменты редактора

Личный вклад

Подготовлены независимый модуль, описание возможностей и проверка существующих тестов.

Текущее состояние

Исходники и EditMode-тесты проверены; публичный пакет и player build пока не подготовлены.

Граф игрового сценария

Playable State Machine отделяет логику последовательности от компонентов сцены. В редакторе создаются состояния, переходы, параметры, маршруты и заметки. Scene UnityEvents связывают вход, выход и тайминги состояния с конкретными действиями игры.

Параметры Bool, Int, Float и Trigger управляют условиями переходов: AND внутри группы, OR между группами. Graph validator проверяет структуру без изменения asset. Runtime API позволяет запускать и останавливать граф, переходить к состоянию и сохранять заранее установленные параметры.

Редактор и установка

Окно открывается через Tools → PSM → State Machine. Полный каталог PlayableStateMachine вместе с .meta копируется в Assets; Runtime, UI, Editor и Tests разделены сборками. UI-поддержка использует uGUI 2.6.0. Демо Flow входит в Samples.

В текущем этапе исправлено выравнивание нативных callback-полей UnityEvent в списке Action Settings. Проверены раскладка, выбор callbacks, numeric drag handles и Undo; runtime-тесты покрывают маршруты, параметры, повторный вход через события и владение fast-forward.

Границы

Fast-forward ускоряет глобальный Time.timeScale и влияет на другие системы игры. Интеграция Animator сохраняет legacy-поведение: прямое воспроизведение без blend переходов controller, сопоставление по имени и несинхронизированный normalized-time clock. Пять characterization-тестов фиксируют эти ограничения; их успех не означает исправление Animator. Отдельный animation adapter пока описан как план.

Проверка и материалы

На Unity 6000.6.0f1 в отдельном проекте с одним модулем прошли 20 EditMode-тестов. Player build, другие версии Unity и performance не проверены. Графическая обложка подписана как заглушка; реальные кадры редактора и видео пока не добавлены. Скачивание и веб-демо не опубликованы.

Другие самостоятельные модули: Scene Audit, Scene Audio и Spline Progress.
