Инструмент Unity В разработке

Scene Audit

Ресурсы сцены, их использование и дубликаты в одном окне Unity Editor.

Роль

Личный инструмент; подробное распределение авторства ещё не описано.

Технологии / направления

Unity / Инструменты редактора / Аудит ресурсов

Личный вклад

Подготовлены независимый модуль, описание возможностей и проверка существующих тестов.

Текущее состояние

Исходники и EditMode-тесты проверены; публичный пакет и player build пока не подготовлены.

Что использует сцена

Scene Audit исследует сериализованные зависимости активной или всех загруженных сцен: материалы, текстуры, meshes, prefabs, shaders, animation clips, controllers, scripts и missing references. Списки показывают ресурсы и места использования, а поиск дубликатов сравнивает хэши файлов и свойства материалов.

Сканирование и поиск дубликатов можно отменить. Модуль не удаляет assets автоматически. В списках поддерживаются выбор диапазона и переключение отдельных строк.

Работа с текстурами

Для выбранных текстур можно изменить Max Size и platform override, затем восстановить предыдущие настройки последней операции. Это изменение TextureImporter во всём проекте. Read-only package assets остаются видимыми, но исключаются из Apply.

Самостоятельная установка

Скопируйте полный каталог SceneAudit с .meta в Assets и откройте Tools → Optimization → Scene Audit. Runtime-сборки нет; другие модули не нужны. В Samples включена сцена Audit. В редакторе доступны четыре пресета оформления.

Проверка и ограничения

В отдельном проекте на Unity 6000.6.0f1 прошли 6 EditMode-тестов: scan scope, duplicates, texture selection/restore, package edit policy и layout. Динамические Resources, Addressables, AssetBundles и reflection могут не попасть в аудит. Editor memory не является размером player build, а keywords не являются отчётом скомпилированных shader variants. Prefab Mode исключён.

Реальные снимки и download пока не опубликованы. Обложка — подписанная графическая заглушка, не кадр Unity.

Связанные инструменты: Playable State Machine, Scene Audio и Spline Progress.
