Unity / Editor tools

A sequence as a graph

States and transitions keep a game sequence separate from scene objects. Events connect entering and leaving a state to game actions.

The sample graph follows Start → Action → Complete with a two-second delay, changing the Game View label at each transition.

Scope

Fast-forward affects the speed of the whole game. Animator integration does not yet blend transitions; the sample graph runs without it.

Captured in Unity on 13 October 2026 using a synthetic sample scene. No public package or web demo is available.
