Playable State Machine

Visual states, transitions and events for game sequences in Unity.

Role

Personal tool; detailed authorship has not been documented yet.

Technologies / disciplines

Unity / Editor tools

Personal contribution

An independent module, feature description and validation of existing tests have been prepared.

Current state

Source and EditMode tests verified; a public package and player build are still pending.

A graph for game sequences

Playable State Machine separates sequence logic from scene components. Its editor provides states, transitions, parameters, routes and notes. Scene UnityEvents bind state entry, exit and timing to game actions.

Bool, Int, Float and Trigger parameters drive transition conditions: AND within a group, OR between groups. A graph validator checks authoring structure without changing the asset. Runtime APIs start and stop playback, jump to a state and preserve parameters set before playback.

Editor and installation

Open Tools → PSM → State Machine. Copy the complete PlayableStateMachine folder with its .meta files into Assets. Runtime, UI, Editor and Tests have separate assemblies; UI support uses uGUI 2.6.0. The Flow sample is included.

This preparation stage corrected the alignment of native UnityEvent callback controls in Action Settings. Existing tests cover layout, callback selection, numeric drag handles and Undo, as well as routes, parameter cleanup, reentrant events and fast-forward ownership.

Boundaries

Fast-forward accelerates the global Time.timeScale and affects other game systems. Animator integration retains legacy behavior: direct playback without controller transition blending, name-based mapping and an unsynchronized normalized-time clock. Five characterization tests record these limitations; passing does not mean Animator has been repaired. A separate animation adapter remains a proposal.

Validation and media

All 20 EditMode tests passed in a separate project containing only this module on Unity 6000.6.0f1. Player builds, other Unity versions and performance have not been verified. The cover is a labelled graphic placeholder; actual editor footage and video are still pending. No download or web demo is published.

Other independent modules: Scene Audit, Scene Audio and Spline Progress.
