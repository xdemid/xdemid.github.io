Progress along a shape

Spline Progress is a uGUI component for closed contours. Its shape helper creates a circle, rectangle, rounded rectangle, triangle, diamond or heart; custom contours use SetSplinePoints. Progress ranges from 0 to 1.

Controls include width, gradient colors, smoothing, rounded endpoints and timeout color. The helper works both at runtime and in the editor.

Rendering and installation

Add UI → Spline Progress to a UI RectTransform. The complete SplineProgress folder with .meta files requires uGUI 2.6.0 and has no dependency on other tools. The legacy PlayWorks.Poker.SplineProgress namespace remains for compatibility and does not require Pokerist.

Its shader is included through Resources and supports stencil masks, RectMask2D and alpha clipping. Each graphic owns a material instance, so a shared source material does not couple animated Progress values. Copies are released on disable/destroy. The Progress demo is included in Samples; Clipper2 and LibTessDotNet ship with licenses.

Validation and boundaries

Fifteen EditMode tests passed in a separate Unity 6000.6.0f1 project, covering shape geometry, non-finite input, shader resources, masks, material isolation/lifecycle and editor layout.

Contours are closed, with up to 32,000 points. Mesh rebuild allocates working buffers; zero allocations are not promised. Player builds, performance, XR and other render pipelines need separate verification.

Other independent modules: Scene Audit, Scene Audio and Playable State Machine.
