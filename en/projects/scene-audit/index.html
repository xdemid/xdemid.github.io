Technologies / disciplines

Unity / Editor tools / Asset audit

Assets and where they are used

Scene Audit shows dependencies in loaded scenes and helps find duplicate textures and materials. Lists connect assets to the objects that use them.

The sample scene contains two groups of duplicates. The tool never deletes files automatically. Selected texture settings can be changed and restored; those changes apply across the Unity project.

Scope

Scanning covers serialized dependencies. Dynamically loaded assets may be absent; Editor memory estimates are not the size of a finished game.

Captured in Unity on 13 October 2026 using a synthetic sample scene. No public package is available.
