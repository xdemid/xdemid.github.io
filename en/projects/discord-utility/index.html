Windows application In development

Obhod

A Windows shell for managing Flowseal zapret: strategies, diagnostics, site rules and updates.

Role

Personal project; the precise authorship breakdown is not documented yet.

Technologies / disciplines

Windows / Desktop

Personal contribution

Prepared the management interface, diagnostics and update workflows, documentation and current-version verification.

Current state

Local shell 0.4.3 with core 1.10.3. Verification on 12 October 2026 passed 186 offline checks; actual ISP connectivity was not tested.

Management in one window

The application combines manual strategy selection, quick and full automatic selection, five parallel HTTPS checks and DNS diagnostics. Separate tabs manage GameFilter and ports, site rules, core updates and rollback, and shell updates.

This is an independent shell, not an official Flowseal product. BAT files are read as data rather than executed. The stack is C#, Windows Forms and .NET Framework 4.8.

Application behaviour

Closing the window hides it in the tray. Exit stops the application’s own process and leaves other processes alone. Checking for updates and downloading are separate: downloading starts after selecting Update.

Windows 10/11 x64, .NET Framework 4.8 and the complete extracted application folder are required. Starting WinDivert requires UAC. A public installer is not provided in this case yet.

Verification and limits

An isolated copy passed 186 offline checks covering launch arguments, automatic selection, settings save and rollback, site lists, ZIP handling, process ownership and update workflows. The driver was replaced with a harmless test process and update responses were simulated.

The first run from a deeply nested folder failed to save a site list; a repeat from a shorter path passed. Path length remains a suspected cause, without a separate application fix. YouTube playback, Discord voice, UAC, driver operation and actual network release installation were not verified in this stage.
