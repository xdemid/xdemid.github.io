Technologies / disciplines

Windows / Desktop

Management in one window

Strategy selection, automatic selection, diagnostics, site rules and updates share one Windows interface. Closing the window minimises it to the tray; downloading an update is a separate action.

This is an independent shell for Flowseal zapret. It requires Windows 10/11 x64 and .NET Framework 4.8; the driver needs administrator privileges.
