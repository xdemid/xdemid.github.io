Current state

Version 0.4 was checked locally on 13 October 2026: Release build and 29 tests. Website publishing and media processing remain future work.

Local project knowledge

Demid Studio is a separate C#/.NET 8 and Avalonia Windows application. Project passports, documents and images remain readable files. Search, document tabs and manual revisions preserve earlier materials. Incoming agent records can be collected by the GUI or CLI.

A more compact workspace

Version 0.4 introduces sidebar navigation, smaller controls and graphite and indigo styling. Project, document and draft lists can be resized; the materials panel can be hidden. The text editor uses the available space. The default window is 1240 × 800, with a 1000 × 640 minimum.

Motion and document forms

Short hover, press and 160 ms appearance effects can be disabled. Fast navigation cancels the previous animation. The document dialog is 700 × 720, with persistent labels and a collapsible attachments section. Animation settings, panels and tabs are currently session-local.

Validation and boundaries

The 13 October 2026 stage passed a Release build with no errors or warnings and 29 tests. Checks covered keyboard navigation, splitter dragging, text preservation, revision creation and animation cancellation. These are documented product results; no Studio tests were rerun during this website update.

The gallery contains actual Avalonia Headless/Skia renders with sample data and animation disabled for capture. These are not native Windows screenshots. Website and social publishing, media processing, docking and layout persistence are not implemented.
