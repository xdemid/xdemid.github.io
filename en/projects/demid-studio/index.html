Shared project knowledge

Demid Studio is an independent Windows application built with C#/.NET 8 and Avalonia. Project profiles, documents and images remain readable files. The application supports browsing documentation, searching text and tags, opening multiple documents in tabs and creating revisions without deleting earlier ones.

Changes in 0.3

New Markdown documents and prepared images are stored in a file-based knowledge library suitable for local Git history. Migration copies older materials and preserves originals. Incoming agent records are processed by the GUI or a separate CLI. There are no automatic Git commits or pushes.

Local verification passed 28 tests and a Release build with no errors or warnings. It covered repeated migration, document and image preservation, tabs during search and navigation, and revision creation through the application form. These results refer to the stage completed on 13 October 2026; a network dependency audit and remote CI for 0.3 were not verified.

Next boundaries

Website and social publishing, editing video, voice-over, media processing and a job queue remain future features. Demid Works operates independently of Studio. The cover is still a graphic placeholder and no public application demo is provided here.
