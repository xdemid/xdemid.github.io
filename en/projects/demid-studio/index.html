Projects and documents together

Demid Studio is a local Windows application for organising projects, documents and drafts. Search and tabs help switch between materials; a new document revision preserves the previous one.

Documents and finished images remain readable files. Migrating older materials preserves their originals.

An adjustable workspace

The 0.4 interface supports resizing lists, hiding the assets panel and disabling animations. Layout preferences last for the current session. Website publishing and media processing are not implemented yet.

The gallery contains Avalonia Headless/Skia renders of the actual interface using sample data.
