Demid Works Website

From an idea and an editorial grid to an independent bilingual product.

Role

Concept, design direction, task definition and review; implementation with an AI assistant.

Technologies / disciplines

Astro / TypeScript / Content Collections

Personal contribution

The owner sets product constraints and reviews the result. An AI assistant creates code and the initial content structure from the brief.

Current state

The site is published on GitHub Pages: two languages, ten cases, seven journal entries and actual Obhod captures. Source files remain private.

Links

Visit the website ↗

The task

Create an independent portfolio that quickly communicates the specialisation and leads to specific work. The website should be a complete case of its own, rather than just a showcase.

Constraints

There are not enough materials for final cases yet. Commercial game screenshots must not be fabricated, experience invented, or future modules presented as working. Contact details and a résumé will follow when supplied by the owner.

Architecture

Astro generates static pages. TypeScript and Zod schemas validate content. Project identity is separate from localised Markdown cases. Journal entries refer to projects using stable IDs. The interface uses shared components and CSS tokens; the catalogue uses a small client module.

Design

A graphite opening, large typography, a strict grid and warm light sections. Temporary graphic studies are explicitly labelled and do not depict game footage. The logo slot can be replaced without rebuilding the navigation.
