The task

Create an independent portfolio that quickly communicates the specialisation and leads to specific work. The website should be a complete case of its own, rather than just a showcase.

Constraints

There are not enough materials for final cases yet. Commercial game screenshots must not be fabricated, experience invented, or future modules presented as working. Contact details and a résumé will follow when supplied by the owner.

Architecture

Astro generates static pages. TypeScript and Zod schemas validate content. Project identity is separate from localised Markdown cases. Journal entries refer to projects using stable IDs. The interface uses shared components and CSS tokens; the catalogue uses a small client module.

Design

A graphite showcase, large typography, a strict grid and yellow accent follow the approved KnowledgeBase template. Temporary graphic studies are explicitly labelled and do not depict game footage. The logo slot can be replaced without rebuilding the navigation.
