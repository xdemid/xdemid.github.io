A portfolio as a product

The site brings applications, tools and visual work into a bilingual catalogue. Each project has its own case with contributions, media and a clear status.

Content separate from presentation

Astro builds static pages from localised text and validated data. Shared components and CSS tokens maintain a consistent grid; content can change without rewriting pages.

Exploring the work

The home page introduces selected projects. The carousel supports manual navigation and pause; images open in a keyboard-accessible viewer. Reduced motion disables automatic rotation.
