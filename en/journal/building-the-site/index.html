The first Demid Works version: content separate from the interface, two languages and honest boundaries.

Demid Works Website ↗

A clear structure first

The first Demid Works stage is a website visitors can explore in full. The home page introduces the direction, the catalogue leads to projects, and cases separate completed work from future plans. TORA has its own dedicated hub.

Content separate from the interface

Project identity lives in JSON; text lives in localised Markdown files. Content Collections and schemas validate the data shape. This makes it possible to extend cases without rewriting components.

What is still missing

Actual media, detailed verified responsibilities, a résumé and contact details are still pending. Labelled placeholders and clear statuses occupy their places. Interactive TORA tools will be a separate stage.

How the website is made

The owner defines the idea, design direction and product requirements. An AI assistant participates in creating code and the initial content structure. Decisions, verification results and limitations are recorded in the project documentation.
