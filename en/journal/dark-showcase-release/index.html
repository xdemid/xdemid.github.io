Demid Works Website ↗

From the approved reference to the website

Cases, cards and journal now use a graphite background, warm light text and a single yellow accent from the KnowledgeBase dark showcase template. Demid Works branding, bilingual structure and verified project material are preserved.

Different work on the first screen

Five projects, starting with NASCAR, replace the fixed architecture image. Manual arrows and pause are available; reduced motion disables automatic rotation. Focus, hover and a hidden tab suspend the timer.

A closer look at actual captures

Cases now have a media hero, personal contribution and two key scenarios where material is available. The image viewer supports arrows, Home/End and Escape, and restores focus on close. Without JavaScript, direct image links and the first home project remain available.

Stage validation

Verified 96 bilingual states at 320, 390, 768 and 1440 px, with no horizontal overflow, missing images or JavaScript errors. Carousel timing, pause, reduced motion, viewer keyboard handling and filters were checked separately. These are website checks; Unity tool and Studio tests were not rerun.
