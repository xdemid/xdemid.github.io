Короткий девлог / 13.10.2026Демо · В разработке

PSM: от графа к смене состояний

Короткий граф меняет текст сцены при переходе между состояниями.

Работы

Playable State Machine ↗

От схемы к действию

Чтобы увидеть связь графа и сцены, достаточно короткого сценария Start → Action → Complete. Двухсекундная задержка делает каждый переход заметным, а событие входа меняет текст в Game View.

Демонстрация показывает последовательность целиком — от настройки перехода до результата. Граф работает без Animator и не демонстрирует его интеграцию.

Кадры сняты 13 октября 2026 на синтетической Unity-демосцене.
