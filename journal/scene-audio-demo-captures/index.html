Scene Audio: от привязки к Event Log

Демонстрационный сценарий и 4 реальных кадров интерфейса с оставшимися ограничениями.

Работы

Scene Audio ↗

Что показано

Создать SoundBank с demo.ping → привязать событие к AudioManager текущей сцены → настроить вариант → запустить demo → проверить Event Log.

Зафиксированный результат

В Play Mode demo.ping поступал каждые 1,5 секунды; реальный Event Log содержит Played, pitch и volume=0.20. Синтетический тон 440 Гц, 0,15 с.

Кадры получены 13 октября 2026 из настоящих интерфейсов Unity 6000.6.0f1 на синтетическом демонстрационном контенте. Продукт остаётся в разработке.

Границы и следующий шаг

Event Log подтверждает маршрут и запуск AudioSource. Снимок не доказывает слышимость на конкретном устройстве. Editor preview отдельно не проверялся.

Player build и производительность требуют отдельной проверки. Здесь приведены результаты этапа захвата, а не новые тесты при обновлении сайта.
